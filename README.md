# Aircraft Fuel and Range Management (AFRM)

A Python prototype developed to simulate aircraft fuel management and support flight-planning calculations.

## Objectives
- Calculate aircraft fuel consumption.
- Estimate remaining fuel, endurance and range.
- Assess fuel status against defined thresholds.
- Process simulated flight data.
- Verify calculations using automated tests.

## Development Environment
- Python 3.15
- Visual Studio Code
- Git and GitHub

## Limitations
This application uses simulated flight data and simplified fuel calculations. It is not intended for operational aviation use.
